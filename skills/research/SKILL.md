---
name: research
description: Investigate a question against high-trust primary sources and capture findings at the configured research location. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.
---

For product discovery, read relevant canonical knowledge through
[consolidate](../consolidate/SKILL.md), including project-scoped external configuration.
Retain the selected question, scope, expected evidence, and completion criterion.
Carry those references and the configuration entry into delegated research.

Spin up a **background agent** to do the research, so you keep working while it reads.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save it at the configured research/work-record location. Otherwise match the
   repository's existing convention, or choose a sensible location and report it.

For locally saved findings, the researcher and final report apply
[local document delivery](../consolidate/references/local-document-delivery.md).

For product work, preserve supported findings through consolidate within existing
documentation authority. Keep observations, interpretations, and proposed policy
distinct; unresolved choices can return to contextual grilling. Use
[next steps](../next-steps/SKILL.md) for remaining requirements or continuation after
the authorized research and applicable persistence are complete.
