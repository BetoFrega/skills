# Advisory

Strongly recommend one independent advisor when another perspective can reduce
uncertainty or reveal risk, especially for the description's triggers. Consultation is discretionary; layer
count alone is insufficient. No per-call user approval is needed.

Apply [model-selection](../model-selection/SKILL.md). Prefer Opus 5.5 when available
and compatible with tools/context, overriding lowest-cost selection. User choices
govern; disclose fallback limitations. Select effort independently and set both
explicitly where supported. Check current Codex or Claude CLI availability and
compatibility; neither CLI is required.

Supply the unresolved question, evidence, constraints, and decision criteria without
seeding a conclusion when independence matters. The advisor investigates/recommends;
the primary agent decides/executes. Evaluate advice against evidence and surface
material disagreement or decision-changing risk. Consultation grants no scope
expansion, mutations, external actions, or further delegation.
