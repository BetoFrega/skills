# Verify

Identify the outcome being claimed or requested and apply [Evidence Before Claims](../beto-mode/principles/evidence-before-claims.md). Use read-only checks and report confirmed, contradicted, or unverified, with supporting evidence and any remaining gap.

Keep this invocation to verification; report fixes or additional access needed without performing them. Ask which outcome to verify if context does not identify one.

For local document delivery claims, apply
[local document delivery](../consolidate/references/local-document-delivery.md)
to verify the intended version against its actual destination.
