From entrypoint to outcome

  1. The route receives the code

    The checkout handler reads the code from the request and loads Ana's cart.

    src/routes/checkout.ts:42

    const cart = await carts.forUser(req.user.id);
const total = await pricing.applyDiscount(cart, req.body.code);

    Inferred In: req.body.code = "WELCOME10". Out: a cart with one item at 100.00.

    Next: src/routes/checkout.ts:43 calls applyDiscount.

  2. The pricing service applies the code

    The service looks up the code and subtracts its percentage. findCode is collapsed: it returns the stored code or null.

    src/pricing/discount.ts:17

    const code = await codes.findCode(input);
if (!code) return cart.subtotal;

    Observed In a run of discount.test.ts: findCode returned { percent: 10 }, and the function returned 90.00.

    • Unknown code: returns the subtotal unchanged, src/pricing/discount.ts:18; checkout continues without a discount.

    Next: the total returns to src/routes/checkout.ts:44.

  3. The repository saves the total

    The handler saves the discounted total and returns it to the page.

    src/orders/repository.ts:61

    await db.orders.update({ id: order.id, total });

    Inferred In: total = 90.00. Out: the order row holds 90.00.

    End of execution: the response carries the saved total.
