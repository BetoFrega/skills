# Present a Majority Challenge

This reference applies only when the judge's supported preference differs from a
strict majority of decider choices. Autonomous acceptance is suspended for this
decision, including any execution that depends on it.

Present one bounded decision to the user:

1. **Decision and disagreement:** the question, majority choice, judge's preference,
   scope, and material conditions.
2. **Defense:** the strongest evidence and rationale for the judge's preference.
3. **Counterdefense:** the strongest evidence and rationale for the majority choice,
   including the strongest objection to the judge's preference.
4. **Evidence limits:** established facts, refuted premises, and remaining uncertainty.
5. **Recommendation and choice:** explain the recommendation and ask the user to choose.

Use the existing reports and verification appendix. Represent both positions fairly;
label a refuted or unsupported premise rather than presenting it as established.
This branch requires neither new research nor additional advocacy agents.

**Complete when:** the user chooses or gives new instructions. Record the decision
and apply its actual scope and existing execution authorization before proceeding.
