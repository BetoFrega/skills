# Status

Use the latest goal, user corrections, and available task evidence. Give a concise account of completed work, work in progress, and blockers or pending decisions. Distinguish local artifacts from confirmed external delivery and label stale or unverified claims.

Keep this invocation informational. Use read-only checks when needed to establish current status; end with the immediate next action, without starting it. If the task cannot be identified, ask which task the user means.

For local document changes, apply
[local document delivery](../consolidate/references/local-document-delivery.md)
to state their Git delivery and immediate remaining step.
