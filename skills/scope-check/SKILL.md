# Scope Check

Recover the latest agreed scope and subsequent user-approved changes. Compare the actual work and remaining plan against it, identifying required work still missing, additions lacking authorization, and decisions deferred by agreement. Use task artifacts when needed; label uncertain scope rather than inventing requirements.

Return a concise assessment with evidence and the smallest correction for each material deviation. Keep this invocation to assessment: preserve existing work and ask about unresolved scope choices without changing the implementation. If no agreed scope is available, ask for the baseline.
