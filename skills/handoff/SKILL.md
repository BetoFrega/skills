# Handoff

Prepare a self-contained continuation brief from the current task: goal, agreed scope, decisions and authorization boundaries, completed work, evidence and relevant artifact locations, remaining blockers, and the immediate next action. Distinguish confirmed results from assumptions and preserve details needed to resume without repeating completed work.

Return the brief in chat, using links to relevant files or external artifacts and excluding secrets. This invocation prepares the handoff; sending it to another chat or person, creating a chat, or moving the task requires separate authorization. Ask which task to summarize if context is ambiguous.
