# Decide

Identify the next unresolved decision that materially affects the current goal, respecting decisions already made. Present only that decision with the context and evidence needed to choose, viable options, their consequences, and your recommendation. Distinguish verified facts from assumptions.

Ask one clear question and end the turn awaiting the user's choice. If no decision remains, say so; if the task is unclear, ask which task the user means.
