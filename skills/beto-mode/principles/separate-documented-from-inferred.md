# Separate Documented From Inferred

Keep what a source states apart from what you conclude.

- Do not invent requirements, business rules, rationale, alternatives that were
  considered, links, identifiers, or citations.
- Mark inference as inference, and name the source behind each documented fact.
- When a needed detail is missing, inspect the accessible sources first; if it is
  still missing, state the precise gap.
- An unanswered question stays open; do not resolve it by assumption to make progress
  look complete.
