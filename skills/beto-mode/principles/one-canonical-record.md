# One Canonical Record

Each fact, rule, decision, and term lives authoritatively in one place.

- Find the canonical record before writing; update it instead of creating a parallel
  copy.
- Link to the record instead of restating it. A summary may add context but does
  not become a second authority.
- When copies already disagree, resolve which one governs and reconcile the others
  to it; bring the conflict to the user when authority is unclear.
- Configuration, scripts, schemas, and help output own their facts; do not cache them
  in prose unless the lookup is expensive.
