# Encode Lessons in Structure

When you catch yourself writing the same instruction a second time, or notice a
recurring correction, encode the rule as a lint, check, metadata flag, test, or script
instead of more text.

- If the fix is structural, use only the structural fix; the repeated instruction was
  the symptom.
- If the lesson needs judgment and cannot be encoded, make the instruction more
  prominent in its one authoritative place and add an example of the failure.
- When an instruction elsewhere causes the recurring mistake, correct that source
  instead of adding a counter-instruction.
