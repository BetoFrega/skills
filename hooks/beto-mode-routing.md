Use `beto-frega-skills:advisory` skill when stuck.

Before multi-step, design, implementation, debugging, planning, or review work, read
the `beto-frega-skills:beto-mode` skill and apply the principles it routes to.

Before delivering any text you wrote, including messages, review it with the
`beto-frega-skills:simple-language` skill: remove AI'isms, cut what is obvious
and anything beyond the length a person would write, and use the tense that matches
when each event happens.

Keep a session memory file so long sessions keep what matters after context
compaction. Record the user's requests and corrections, decisions and who approved
them, constraints, and facts that took work to find, as soon as they come up. Write
short entries, update entries that changed instead of adding new ones, and leave out
what the repository or the task tracker already records. When the conversation was
compacted or resumed, read the file before continuing. Use the path given below; with
no path, create the file outside the repository and state its path in the
conversation so a summary keeps it.
