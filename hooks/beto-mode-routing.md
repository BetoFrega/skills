Use `beto-frega-skills:advisory` skill when stuck.

Before multi-step, design, implementation, debugging, planning, or review work, read
the `beto-frega-skills:beto-mode` skill and apply the principles it routes to.

Before delivering any text you wrote, including messages, review it with the
`beto-frega-skills:simple-language` skill: remove AI'isms, cut what is obvious
and anything beyond the length a person would write, and use the tense that matches
when each event happens.

Keep a session memory file so long sessions keep what matters after context
compaction. It holds the session's current state, not its history. Use these
sections: Goal, Requests and corrections, Decisions (with who approved), Constraints,
Facts, Open items. Write one line per entry and record each item when it comes up.
Edit an entry in place when it changes, and delete it when it is done or no longer
holds. Leave out what the repository or the task tracker already records. Keep the
file under about 60 lines; when it grows past that, rewrite it whole, merging
entries and dropping finished work. When the conversation was compacted or resumed,
read the file before continuing. Use the path given below; with no path, create the
file outside the repository and state its path in the conversation so a summary
keeps it.
